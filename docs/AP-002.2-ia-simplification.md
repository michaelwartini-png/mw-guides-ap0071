# AP-002.2 — Informationsarchitektur der Startseite: Entscheidungen

Kurzes Protokoll der Änderungen, für alle, die die Historie nicht über
CHANGELOG.md nachvollziehen wollen.

## Problem

Homepage nutzte "Ride Guides"/"Explore Trips" nur in der Navigation.
Weiter unten auf der Seite tauchten diese Begriffe nicht mehr auf —
stattdessen redaktionelle Überschriften ohne erkennbaren Bezug zu den
zwei Erlebniswelten. Zusätzlich existierte mit "Reiseideen"/"Magazin"
eine dritte, nicht vorgesehene Content-Ebene (Ergebnis von AP-002, vor
dieser Korrektur).

## Entscheidung 1 — Keine dritte Content-Ebene

"Reiseideen" wurde vollständig in "Explore Trips" überführt:

- `types/travelIdea.ts` + `types/exploreTrip.ts` (zwei konkurrierende
  Typen) → ein gemeinsamer Typ in `types/exploreTrip.ts`.
- `content/travelIdeas.ts` → `content/exploreTrips.ts`. Die drei echten
  Artikel (125 Jahre Schwebebahn, Die neue Generation, Warum wir
  dieselbe Kurve immer wieder fahren) sind **inhaltlich unverändert**
  übernommen — nur `category` → `theme` umbenannt.
- `/reiseideen` und `/reiseideen/[slug]` entfernt. Alte URLs leiten per
  308 (permanent) auf `/explore-trips` bzw. `/explore-trips/[slug]` um
  (`next.config.ts`), damit kein bestehender Link ins Leere läuft.
- Die vorherige AP-002-Roadmap-Liste für Explore Trips wurde durch die
  in diesem Auftrag aktualisierte Beispielliste ersetzt (u. a. "Bodensee
  ohne Auto" statt "Bodensee", neu: "Schwebebahnen der Welt",
  "Straßenbahnstädte Europas", "Bahnreisen").
- Navigation: "Magazin"-Punkt entfernt, drei statt vier
  Hauptnavigationspunkte (Ride Guides, Explore Trips, Über MW Guides).

## Entscheidung 2 — Homepage-Reihenfolge exakt wie im Auftrag

1. Hero (unverändert)
2. Unsere Haltung — `BrandIdea` (unverändert)
3. Unsere Arbeitsweise — `WhyMWGuides`, "Wir reisen zuerst." (unverändert)
4. **Ride Guides** — `PopularTours`, Überschrift von "Jede Tour erzählt
   eine Geschichte." auf den wörtlichen Begriff "Ride Guides" plus die
   im Auftrag vorgegebene Erklärzeile geändert
5. **Explore Trips** — neue Sektion `ExploreTripsSection`, exakt gleiche
   Struktur wie Ride Guides, zeigt die drei echten Explore Trips
6. Jede Stadt hat eine Geschichte — `EveryCityHasAStory` (unverändert)
7. So entsteht eine Tour — `TravelerMoments` (unverändert, nur der Link
   auf den vertiefenden Artikel zeigt jetzt auf `/explore-trips/...`)

**Abweichung vom Auftrag:** "Reisen wie ein Einheimischer" (`HowItWorks`)
wurde in der Auftragsliste nicht erwähnt. Da der Auftrag an anderer
Stelle wiederholt betont, keine Inhalte zu entfernen, wurde die Sektion
beibehalten und an ihrer bisherigen relativen Position (unmittelbar vor
"So entsteht eine Tour") belassen, statt sie zu streichen.

## Verifiziert

`npx tsc --noEmit`, `npm run lint`, `npm run build` erfolgreich. Homepage
zeigt die Überschriften in exakt dieser Reihenfolge: "Wir reisen
zuerst." → "Ride Guides" → "Explore Trips" → "Jede Stadt hat eine
Geschichte." → "Reisen wie ein Einheimischer." → "So entsteht eine
Tour." Alte `/reiseideen`-URLs liefern 308 auf die neuen
`/explore-trips`-URLs. Keine neuen Abhängigkeiten.
