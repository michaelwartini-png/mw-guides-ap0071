## Iteration 1 — Änderungen

### 1. Hero

| Änderung | Umsetzung |
|---|---|
| Breadcrumb oberhalb Hero | `ErlebnisprofilBreadcrumbs` via `website.breadcrumbs` in `app/erlebnisse/[slug]/page.tsx` |
| Referenz-Layout | Katamaran-Maße (`min-h-[420px]`), Gradient, Badge-only, Subtitle 16px |
| Stats-Karte rechts | `HeroStatsCard` (Website-Modus) |
| Ride-Guide-CTA im Hero | `RideGuideCta` unter Subtitle (Link zu `/touren/schwebebahn`) |
| Keine Admin-Elemente | `mode="website"` blendet Slots aus |

### 2. Score-Bar

| Element | Status |
|---|---|
| MW Guides Score | ✅ |
| Google + Tripadvisor (prominent) | ✅ `PlatformReviewsStrip` |
| Bewertungskategorien | ✅ |
| Ride Guide verfügbar | ✅ |

| Ride Guide starten (CTA) | ✅ rechts, verlinkt |
| Layout/Abstände | ✅ Katamaran-Pattern |

### 3. Informationsblock

Neue Sektion `OverviewSection` — 3-Spalten-Grid wie Katamaran:

- **Links:** Das Erlebnis + Feature-Liste
- **Mitte:** Karte + Anreise-Infos
- **Rechts:** Offizielle Informationen + Praktische Informationen + Betreiber

Ersetzt die zuvor getrennten Sektionen Description, Map, Official, Practical, Operator im Renderer.

### 4. Galerie

- Horizontal-Slider entfernt
- Einheitliches Grid: `grid-cols-2/3/4`, `aspect-[4/3]`, `gap-3`, `rounded-xl`
- Lightbox bleibt erhalten

### 5. Bewertungen

- Titel „Bewertungen im Überblick" (Katamaran)
- Kompaktere Karten, einheitliche Abstände
- MW Guides Score bleibt im Abschnitt

### 6. Website-Einbindung

`ErlebnisprofilWebsiteOptions` (Renderer-Prop, kein Produktmodell):

```typescript
website={{
  breadcrumbs: [...],
  rideGuide: { href, label, price },
}}
```

Ride-Guide-Mapping: `wuppertaler-schwebebahn` → `/touren/schwebebahn` (Preis aus `content/tours.ts`).
